# Versão 1 — "PayFlow 1f Fluxo Mono" (salva em 28/09/2026)

Origem: projeto Claude Design "PayFlow: Três direções visuais"
https://claude.ai/design/p/4c53e7b8-3387-4cb3-9af4-42c3cacc3591?file=PayFlow+1f+Fluxo+Mono.dc.html

Arquivos:
- `PayFlow 1f Fluxo Mono.dc.html` — protótipo escolhido (cores, formas, telas). Abre no navegador.
- `support.js` — runtime do protótipo (importado pelo HTML).

Direção visual: paleta monocromática (preto/off-white), imposto (IBS/CBS) destacado em ocre,
fontes Instrument Sans (texto) + JetBrains Mono (valores), cantos 14px, tema claro e escuro.

Telas do protótipo: landing · criar conta · home (saldo) · transferir (com split de imposto)
· transferência enviada · extrato (com filtros) · contas · painel do governo (IBS/CBS).
