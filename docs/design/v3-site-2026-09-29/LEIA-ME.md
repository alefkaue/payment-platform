# Versão 3 — "PayFlow Site" (29/09/2026)

Página web (site institucional) do PayFlow, no estilo Fluxo Mono, com Bootstrap 5.3 (grid e responsividade).
Estrutura inspirada em sites de pagamento como o do PayPal (navbar, hero com Pessoal/Empresas, cards,
blocos alternados, seção escura de segurança, FAQ, rodapé) — com marca, textos e visual próprios do PayFlow.

Seções: navbar (menu no celular) · hero Pessoal/Empresas · recursos · simulador de split IBS/CBS (2026 teste / 2027 simulação)
· segurança (biometria) · para empresas · como começar · perguntas frequentes · CTA · rodapé.
Os botões "Entrar"/"Abrir conta" levam ao protótipo do app (1g).
