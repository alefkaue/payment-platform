ASTRO

O Astro é um banco de celular.

O produto é o app Android. No computador, rode o app num emulador Android (guia abaixo). A versão web serve só para testes da equipe.

Baixar Astro (Android)

Com todas as proteções ligadas: pinning, atestação, sem print, sem depuração.

Vai fazer o pentest?

O desafio é achar falhas num banco que foi feito para ser seguro, inclusive nas proteções do próprio app. Comece pelo guia e pelas regras.
